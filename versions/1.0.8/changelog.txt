This update contains all the changes from the previously pulled 1.0.7 version, plus the following:

- Fixed [#1](https://github.com/pajicadvance/affogato/issues/1)
- Fixed [#2](https://github.com/pajicadvance/affogato/issues/2)
- Fixed [#4](https://github.com/pajicadvance/affogato/issues/4)
- Removed Storage Labels (see [#3](https://github.com/pajicadvance/affogato/issues/3))
- Rebalanced the enchantment upgrade mechanic
  - Upgrading now costs diamonds instead of lapis
  - The amount of diamonds required is based on the upgraded enchantment's current level
  - Duplicating the template now requires less diamonds (diamond block -> diamond)
- Added Numeral Ping
- Updated default Mixtape config
  - If you had your own changes to Mixtape's config, you'll have to redo them
